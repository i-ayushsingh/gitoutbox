# Support

Thank you for using GitOutbox! We want to ensure you have a smooth experience. Please review the channels below to find support or report issues.

---

## 1. Questions & Discussion

For general questions, configuration help, or discussing ideas with the community:
* **GitHub Discussions**: Open a thread in the [Discussions](https://github.com/i-ayushsingh/gitoutbox/discussions) tab of our repository.
* **FAQ**: Check out our [Frequently Asked Questions Guide](file:///c:/Projects/Gitlater/docs/faq.md) for quick answers to common issues.

---

## 2. Reporting Bugs

If you encounter unexpected behavior, crashes, or failed executions:
1. **Search Existing Issues**: Look through active [GitHub Issues](https://github.com/i-ayushsingh/gitoutbox/issues) to see if the bug has already been reported.
2. **Collect Logs**:
   * Inspect the Activity tab in the GitOutbox UI to locate the error trace.
   * On Windows, check the application data logs folder at: `C:\Users\<username>\AppData\Roaming\app.gitoutbox.desktop\logs`.
3. **Open a Bug Report**: If the bug is new, open a [Bug Report Issue](https://github.com/i-ayushsingh/gitoutbox/issues/new) on GitHub. Please include:
   * Steps to reproduce the issue.
   * Staging log outputs and error messages.
   * Git and Windows versions.

---

## 3. Feature Requests

We welcome ideas for new features!
* **Submit a Proposal**: Open a new [Feature Request Issue](https://github.com/i-ayushsingh/gitoutbox/issues/new) on GitHub. Describe your use case and how the proposed feature fits into GitOutbox's local-first, safe Git scheduling philosophy.

---

## 4. Security Vulnerabilities

If you discover a security vulnerability, please **do not** file a public issue. Refer to our [SECURITY.md](file:///c:/Projects/Gitlater/SECURITY.md) for instructions on how to report it privately.
